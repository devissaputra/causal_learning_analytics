# Research Bundle Visuals

This directory contains explanatory diagrams for the frozen study design. Empirical result figures are generated by scripts/run_oulad_study.py into results/figures/.

## Explanatory diagrams

- architecture.svg — day-30 landmark study architecture;
- data_flow.svg — temporal and analytic evidence flow.

## Generated empirical figures

- results/figures/propensity_overlap.png;
- results/figures/balance_love_plot.png;
- results/figures/weight_distribution.png;
- results/figures/propensity_specification_sensitivity.png.

The PNG figures are generated from the actual OULAD analysis and are research evidence. The SVG diagrams are explanatory study-design figures and do not contain invented numerical results.
